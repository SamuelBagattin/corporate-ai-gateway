# Architecture

## Stack
- AWS EKS
- Terraform
- Helm
- ArgoCD (GitOps)
- LiteLLM (proxy)
- Langfuse (observability, with Postgres + ClickHouse)
- vLLM serving open-weight models on CPU nodes (POC budget is very low)
- Amazon Bedrock (v2)
- Platform: Karpenter, AWS Load Balancer Controller, external-dns, External Secrets, cert-manager, CloudNativePG, ClickHouse operator

## Structure
- `terraform/` — single root module: VPC, EKS, Karpenter IAM, Pod Identity roles, Route53 sub-zone + ACM, Langfuse S3, Secrets Manager, ArgoCD install + root app. Backend in `backend_vars/s3.tfvars`, inputs in `terraform.tfvars`.
- `gitops/bootstrap/` — app-of-apps chart; `values.yaml` lists every Application (path, namespace, sync wave, templated values).
- `gitops/platform/<name>/` — umbrella charts for cluster add-ons (upstream chart as dependency + local templates).
- `gitops/apps/<name>/` — workloads: `vllm` (local chart), `litellm`, `langfuse` (umbrella + CNPG Cluster + ExternalSecrets).
- `scripts/` — `create.sh` (apply), `sleep.sh` / `wake.sh` (nodes to 0 and back), `destroy.sh` (ordered teardown + `terraform destroy`); shared helpers in `lib.sh`, which reads the `ops` Terraform output.

## Key decisions
_Append decisions in reverse-chronological order. One paragraph each: what, why, what was rejected. Date every entry._

### 2026-10-19 — Operations: manual sleep/wake, destroy/create for long breaks
Cost control is manual (user's choice): `sleep.sh` pauses ArgoCD auto-sync for `bootstrap` and `karpenter`, sets NodePool CPU limits to 0, deletes NodeClaims, drains the system node and scales its node group to 0; `wake.sh` reverses it and lets ArgoCD restore the NodePools from Git. Asleep ≈ 120 USD/month (control plane, ALB, NAT instance, EBS). `destroy.sh` / `create.sh` rebuild from scratch (data lost) for long breaks. Rejected: scheduled scaling (not wanted), keeping persistent data across destroys (not needed for a POC).

### 2026-10-19 — Bootstrap: Terraform installs ArgoCD + root app, then GitOps
Terraform `helm_release` installs `gitops/platform/argocd` once (`ignore_changes = all`), then an `argocd-apps` root Application pointing at `gitops/bootstrap`. Account-specific values (cluster name, VPC, cert ARN, bucket, queue, domain) flow from Terraform into the root app's `valuesObject` and down to every child as `.Values.global`, so nothing account-specific is committed under `gitops/`. Root app and the self-managed `argocd` app have no resources finalizer (no accidental cascade). Rejected: hard-coding ARNs in values (not reproducible), ApplicationSets (overkill for one cluster).

### 2026-10-19 — Compute: one system node + Karpenter for inference
A single-node managed group (r7g.large-class spot, single AZ, untainted) runs Karpenter, ArgoCD, add-ons, platform controllers and the Langfuse/LiteLLM stack; VPC CNI prefix delegation + `maxPods: 110` lift the 29-pod ENI limit. Karpenter NodePools: `inference` (Graviton3+ for BF16, tainted `workload=inference`, `vllm/vllm-openai-cpu` arm64 image) for vLLM, `general` (Graviton, spot) for overflow. Single AZ keeps EBS volumes next to the node across sleep/wake. Rejected: tainted 2-node system group + separate general node (~20 USD/month more), x86 AVX-512/AMX for vLLM (~14 USD/month more), Fargate for Karpenter (ArgoCD needs nodes first), EKS Auto Mode (surcharge), GPUs (budget).

### 2026-10-19 — AWS access: EKS Pod Identity everywhere
Every controller/app with AWS calls (EBS CSI, LB controller, external-dns, External Secrets, Karpenter, Langfuse S3) gets a dedicated role via Pod Identity; no IRSA annotations, no static keys. VPC CNI keeps the node-role policy (module default).

### 2026-10-19 — Secrets: Terraform → Secrets Manager → External Secrets
Terraform generates all app secrets (`random_*`) into `corporate-ai-gateway/litellm` and `.../langfuse`; a `ClusterSecretStore` syncs them. Charts are never allowed to generate secrets. Langfuse headless init (org, project, API keys, admin) uses the same keys LiteLLM reads, so tracing works with no manual step.

### 2026-10-19 — Datastores
One CloudNativePG `Cluster` per app (LiteLLM, Langfuse), passwords generated by CNPG. ClickHouse + Keeper via the official ClickHouse operator (as required by Langfuse chart v2), 1 replica each. Valkey from the Langfuse chart. Langfuse blobs in AWS S3. Rejected: RDS (cost), chart-bundled Postgres per app (two different mechanisms), SeaweedFS/MinIO (S3 is native).

### 2026-10-19 — Networking and exposure
3 AZs, private subnets, egress through one fck-nat instance (t4g.nano, ~3 USD/month vs ~35 for a NAT gateway), S3 gateway endpoint (ECR layers and Langfuse objects skip the NAT). No customer-managed KMS key (EKS default envelope encryption). Delegated Route53 sub-zone `ai-gateway.<parent>` (external-dns only writes there) with a wildcard ACM cert. One internet-facing ALB shared by all Ingresses (`group.name: ai-gateway`), CIDR-restrictable via `ingress_allowed_cidrs`. LiteLLM → Langfuse via the `langfuse_otel` callback.

## Conventions
- Resource requests on every container; POC sizes, single replicas.
- Upstream charts are pinned as dependencies of a local umbrella chart; `Chart.lock` committed, `charts/*.tgz` ignored.
- New Application = one entry in `gitops/bootstrap/values.yaml`.

## Known gotchas
- ArgoCD renders with `helm template`: chart-side `lookup` / `randAlphaNum` / `genCA` regenerate on every sync. Supply secrets explicitly (Langfuse) and use cert-manager for webhook certs (LB controller `enableCertManager`).
- Pod Identity injects credentials at pod creation: associations must exist before pods (add-on `pod_identity_association`, `depends_on` on the root app).
- LiteLLM's migration Job is an ArgoCD PreSync hook, which runs before its DB exists → disabled; the proxy migrates at startup.
- `values` blocks in `gitops/bootstrap/values.yaml`: `nindent` counts from the block, not the file. The template fails on invalid YAML.
- Controllers create AWS resources outside Terraform (ALB, EBS, EC2): always tear down with `scripts/destroy.sh`.
- Single-replica apps have PDBs that block eviction: NodePools set `terminationGracePeriod: 10m`, and `sleep.sh` drains the system node with `--disable-eviction`.
- ArgoCD self-heal reverts manual patches (e.g. NodePool limits): pause auto-sync on the owning app first (`argocd_autosync` in `scripts/lib.sh`).
- Helm: a parent chart's `global.*` overrides the subchart's own `global.*`. Our `global.domain` (base domain) clobbers `argo-cd.global.domain`, so ArgoCD's hostname/url are set explicitly.
- vLLM CPU on arm64: needs `--enforce-eager` (Inductor gcc crash) and is pinned to v0.30.0 (v0.31/v0.32 crash on first request without Triton; fixed by vllm#61992). vLLM checks the KV cache against cgroup limit minus usage, page cache included.
- Langfuse web needs > 500 MB of V8 heap at startup: 2Gi limit + `NODE_OPTIONS=--max-old-space-size=1536`.
- `samuelbagattin.com` DNS is served by Cloudflare, not the Route53 zone of the same name: the `ai-gateway` NS delegation lives in Cloudflare (manual for now; sub-zone name servers change on every destroy/create).
